# Role & Permission Matrix

| งาน | Admin | Receptionist | Nurse | Doctor | Pharmacist | Cashier |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| ผู้ป่วยทั่วไป | ✓ | อ่าน/เขียน | อ่าน | อ่าน | - | - |
| นัดหมาย/คิว | ✓ | ✓ | อ่าน | อ่าน | - | - |
| คัดกรอง | ✓ | - | ✓ | อ่าน | - | - |
| เวชระเบียน/วินิจฉัย | ✓ | - | - | ✓ | อ่านใบสั่งยา | - |
| ใบสั่งยา | ✓ | - | - | สั่ง | จ่าย | - |
| รับยา/สต็อก | ✓ | - | - | อ่าน | รับเข้า/อ่าน | - |
| ปรับสต็อก | ✓ | - | - | - | - | - |
| Invoice/Payment | ✓ | - | - | - | - | ✓ |
| ผู้ใช้/ตั้งค่า/Audit/Backup | ✓ | - | - | - | - | - |

ผู้ใช้หนึ่งคนมีหลาย Role ได้ใน `rolesJson`. Backend เป็นผู้ตัดสินสิทธิ์เสมอและไม่เชื่อ Role จาก Browser.
